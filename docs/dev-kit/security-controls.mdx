# Security controls

Trang này ghi lại các security control đang có runtime trong checkout desktop `dev-kit-app/`, kèm evidence path và rủi ro còn lại. Kiến thức
threat model, protected assets và security principles nằm ở
[Security model](/dev-kit/security). Boundary contract giữa UI, bridge và gateway

## Remaining security risks

- **Application-layer SQLite encryption**: Sensitive fields nằm trong crypto envelopes, nhưng SQLite file và nhiều metadata record (ví dụ note title, host/username) vẫn plaintext local. Đây không phải full-database encryption hay SQLCipher.
- **Unlocked-process exposure**: Khi vault unlocked, DEK và plaintext tạm thời nằm trong process memory. Attacker có quyền đọc memory hoặc debug process local vẫn có thể trích xuất secret sau khi unlock.
- **Production evidence đã mở rộng**: deployed matrix G1–G4 pass qua `cmd/synce2e/`
  trên Compose stack (`7708b99`). Self-service revoke API + Redis device denylist
  TTL 60s đã **design-approved** (`2026-08-11-be-phase-b-device-revoke-design`);
  hardened edge rate limit, Keycloak logout và key-rotation runbook vẫn later.
- **Chưa có MCP/external plugin runtime**: MCP (`internal/mcp`), external plugins (`internal/plugins`) và marketplace (`internal/marketplace`) chưa tồn tại. Future surfaces cần threat model và policy mở rộng trước khi ship.
- **Multi-agent boundaries (residual)**: Loopback TCP vẫn kết nối được (cần egress proxy) và `codegraph.*` vẫn ở mức `project:active` (cần Workspace).
- **Sandbox nới cho auth vendor (2026-09-05)**: Claude adapter cấp read-write
  `~/.claude` + `~/.claude.json`, cộng read `~/Library/Keychains` và
  `mach-lookup com.apple.SecurityServer` (`Policy.AllowKeychain`), vì OAuth
  token của đăng nhập subscription nằm trong macOS Keychain chứ không phải file
  hay env var. Hệ quả: bất cứ thứ gì chạy trong jail đó đọc được credential của
  agent. Nhượng bộ có chủ ý, giới hạn ở đúng những path đó — có test chặn việc
  cấp cả `$HOME` — nhưng nó thu hẹp khoảng cách giữa "agent bị prompt injection"
  và "credential bị lộ". Xem
  [Agent Hub § Vendor agent cần gì để xác thực](/dev-kit/agent-hub#vendor-agent-cần-gì-để-xác-thực-implemented).
- **Deny của Seatbelt từng vô hiệu với path dưới symlink (đã sửa 2026-09-05)**:
  profile emit path nguyên văn trong khi Seatbelt khớp path đã resolve, nên cả
  allow lẫn deny đều không khớp. `TestSeatbeltDeniesDotSSH` pass **do vô tình** —
  không ai đọc được gì cả. Nay cả hai phía phát đủ hai cách viết; xem
  [Sandbox § Symlink](/dev-kit/sandbox#symlink-allow-và-deny-đều-phải-resolve-implemented).
- **Production assumptions chưa được verify end-to-end**: Audit persistence, backup/restore under adversarial disk access, update signing, centralized logging redaction và hardened deployment profile vẫn ngoài scope runtime hiện tại và cần review riêng trước production rollout.
