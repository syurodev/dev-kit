**Goal:** Ship DevKit **Agent Hub** as a built-in module: multi-tab ACP client sessions (mock + Claude adapters), Capability Gateway–gated orchestration, SQLite session/turn storage, UI streaming, and MCP tools (`agenthub.*`) so one agent can invoke another — matching `/dev-kit/agent-hub`.

**Architecture:** `internal/acp` owns vendor-agnostic ACP v1 types + line-delimited JSON-RPC/stdio transport + subprocess lifecycle. `internal/agenthub` owns `VendorAdapter` registry, session orchestration, depth/cycle guard, permission mediation (via `interaction.Hub` / UI — **no auto-approve**), and SQLite persistence. Bridge + MCP both call `AgentHubService` through `AppService.Call` (same gateway path as every other module). Frontend registers module `agenthub` with a multi-tab workbench view.

**Tech Stack:** Go 1.26 (`GOTOOLCHAIN=auto`), existing SQLite migrations (`internal/storage`), `interaction` hub, MCP `go-sdk`, React/Vite/bun frontend, `go-task`. **No** community ACP Go SDK — hand-roll transport + types (design NFR).

**Spec sources (authoritative):**
- `syurodev/base` → `content/projects/dev-kit/agent-hub.mdx`
- Related: `mcp-agent.mdx`, `technical-contracts.mdx`, `roadmap.mdx` (Phase 4)

**Explicitly out of scope (this plan / v1):**
- ACP protocol version 2
- Codex / Gemini vendor adapters (registry must accept them; only **mock** + **claude** ship)
- Auto-detect / install agent CLIs on the machine
- Intent-based agent router
- Multi-client collaborative viewing of one session (AHP-style)
- Async job / polling API for `invokeAgent` (v1 is **blocking**)
- Opt-in cloud sync of session/transcript data (local-only)
- Code Graph integration beyond “call via gateway later” (Code Graph module may not exist yet)
- Auto-approve permissions / “yolo” mode

**Concrete defaults (open questions locked):**

| Item | Decision |
|---|---|
| ACP types | Hand-roll Go structs from [ACP v1 schema](https://agentclientprotocol.com/protocol/v1/schema); keep golden JSON fixtures under `internal/acp/testdata/`. Codegen deferred (ADR follow-up). |
| Transport | Self-implemented line-delimited JSON-RPC 2.0 over stdio (one JSON object per line) |
| Vendors in v1 | `mock` (tests + headless demo) + `claude` (spawn `@agentclientprotocol/claude-agent-acp` via `npx` or configured binary) |
| Max invoke depth | `3` (`parent == nil → depth 0`; creating/invoking child increments; exceed → `agenthub.depthLimitExceeded`) |
| Cycle guard | Walk `parentSessionId` chain; if target appears in ancestors → `agenthub.cycleDetected` |
| Permission | No auto-approve. Mediate via UI/interaction; timeout **60s** → reject (fail closed) |
| Cancel kill ladder | `session/cancel` → wait **5s** → `SIGTERM` → wait **5s** → `SIGKILL` |
| Invoke timeout | Default **10m** context deadline on blocking `invokeAgent` / tab prompt (override via option later; not required in v1 API) |
| Session IDs | DevKit owns stable UUIDs for hub sessions; ACP agent `sessionId` stored as `acpSessionId` separately |
| Storage | New SQLite tables via migration **v13**; not vault-encrypted; not synced |
| MCP tool names | Exactly: `agenthub.listAgents`, `agenthub.createAgentSession`, `agenthub.invokeAgent`, `agenthub.getSessionStatus`, `agenthub.cancelAgent` |
| Subject / caps | Subject `builtin.agenthub`; caps `agenthub:read`, `agenthub:execute` |
| `_meta` | Always persist raw `json.RawMessage`; only adapters normalize usage/tool details |
| Headless / server mode | Mock adapter works; Claude spawn may work if `npx`/binary present; permission prompts fail closed when no Prompter (same spirit as MCP interaction) |
| Events to UI | Wails/server event `agenthub:sessionUpdate` with `{sessionId, update}` payload |

```go
package acp

import (
	"bufio"
	"encoding/json"
	"fmt"
	"io"
)

type Request struct {
	JSONRPC string          `json:"jsonrpc"`
	ID      any             `json:"id"`
	Method  string          `json:"method"`
	Params  json.RawMessage `json:"params,omitempty"`
}

type Response struct {
	JSONRPC string          `json:"jsonrpc"`
	ID      any             `json:"id"`
	Result  json.RawMessage `json:"result,omitempty"`
	Error   *RPCError       `json:"error,omitempty"`
}

type Notification struct {
	JSONRPC string          `json:"jsonrpc"`
	Method  string          `json:"method"`
	Params  json.RawMessage `json:"params,omitempty"`
}

type RPCError struct {
	Code    int             `json:"code"`
	Message string          `json:"message"`
	Data    json.RawMessage `json:"data,omitempty"`
}

// Message is a decoded inbound line (request, response, or notification).
type Message struct {
	JSONRPC string          `json:"jsonrpc"`
	ID      json.RawMessage `json:"id"` // null/absent for notifications; present for req/resp
	Method  string          `json:"method,omitempty"`
	Params  json.RawMessage `json:"params,omitempty"`
	Result  json.RawMessage `json:"result,omitempty"`
	Error   *RPCError       `json:"error,omitempty"`
}

func WriteMessage(w io.Writer, v any) error {
	b, err := json.Marshal(v)
	if err != nil {
		return err
	}
	_, err = w.Write(append(b, '\n'))
	return err
}

func ReadMessage(r io.Reader) (Message, error) {
	br, ok := r.(*bufio.Reader)
	if !ok {
		br = bufio.NewReader(r)
	}
	line, err := br.ReadBytes('\n')
	if err != nil {
		return Message{}, err
	}
	var m Message
	if err := json.Unmarshal(bytesTrimSpace(line), &m); err != nil {
		return Message{}, fmt.Errorf("acp: decode: %w", err)
	}
	if m.JSONRPC != "2.0" {
		return Message{}, fmt.Errorf("acp: bad jsonrpc %q", m.JSONRPC)
	}
	return m, nil
}

func bytesTrimSpace(b []byte) []byte { /* trim \r\n space */ }
```

Adjust `ID` typing as needed so responses correlate (use `json.Number` / `float64` / string consistently — document choice in comment: prefer unmarshaling id into `any` via intermediate map if tests need it).

```go
package acp

type ClientHandler interface {
	RequestPermission(ctx context.Context, params json.RawMessage) (json.RawMessage, error)
	SessionUpdate(ctx context.Context, params json.RawMessage) error
	// UnknownMethod returns a JSON-RPC error payload for unsupported agent→client methods (e.g. fs/*).
	UnknownMethod(ctx context.Context, method string, params json.RawMessage) (json.RawMessage, error)
}

type Conn struct {
	rw      io.ReadWriteCloser
	handler ClientHandler
	// mu, pending map[id]chan Response, nextID, serve loop...
}

func NewConn(rw io.ReadWriteCloser, h ClientHandler) *Conn
func (c *Conn) Serve(ctx context.Context) error
func (c *Conn) Call(ctx context.Context, method string, params any, result any) error
func (c *Conn) Notify(ctx context.Context, method string, params any) error
func (c *Conn) Close() error
```

Recommended interface:

```go
type AgentType string

const (
	AgentTypeMock   AgentType = "mock"
	AgentTypeClaude AgentType = "claude"
)

type NormalizedUsage struct {
	CostUSD      float64
	InputTokens  int
	OutputTokens int
	RawMeta      json.RawMessage // always set to input meta copy
}

type VendorAdapter interface {
	Type() AgentType
	// Open starts a vendor session runtime for cwd (spawn or in-process).
	Open(ctx context.Context, cwd string) (SessionRuntime, error)
	NormalizeUsage(meta json.RawMessage) (NormalizedUsage, error)
	NormalizeToolSummary(meta json.RawMessage, update json.RawMessage) (filesChanged []string, summary string, err error)
	Extensions() []string // e.g. custom methods UI may expose
}

type SessionRuntime interface {
	ACPSessionID() string
	Prompt(ctx context.Context, text string) (PromptOutcome, error)
	Cancel(ctx context.Context) error
	Close(ctx context.Context) error
	// SetHandlers wires permission + update callbacks before Prompt.
	SetHandlers(h RuntimeHandlers)
}

type RuntimeHandlers struct {
	OnUpdate     func(update json.RawMessage, meta json.RawMessage)
	OnPermission func(ctx context.Context, params json.RawMessage) (json.RawMessage, error)
}

type PromptOutcome struct {
	StopReason string
	Meta       json.RawMessage
```
